# Project overview

## Goal

Run Heretic v2.0.0.dev0 on LiquidAI/LFM2.5-230M and look for settings that reduce refusals to 0/100 with as little KL divergence as possible. Later runs extended the same search to SmolLM2-135M-Instruct, LFM2.5-350M, and EuroLLM-1.7B-Instruct.

## Setup

Testing ran on a rented Linux VM with two Tesla T4 GPUs. Credentials and tokens were kept out of the repo.
